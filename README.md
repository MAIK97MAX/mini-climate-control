# MMAD Smart Home Solutions – Climate Control

Embedded climate-control system developed as part of our HTL diploma project.

The system uses an ESP32-S3 as the central controller to monitor temperature sensors and control a thermoelectric heating/cooling unit and ventilation fans.

## Features

- ESP32-S3 central controller
- Thermoelectric heating and cooling
- PWM fan control
- Wireless temperature sensors
- Local OLED status display
- Wi-Fi web interface
- USB-C and 12 V power input
- Custom 4-layer PCB

## Repository

This repository contains the hardware design, firmware and related project files.
